# TIDAL-3 neural data

Generated by `specs/_tests/make-tidal-3-data.py` using NumPy only.

## Models

| Model | Architecture | Data |
|---|---|---|
| MODEL-α | MLP 8-24-12-4 | **REAL** NumPy training run on synthetic 4-class data |
| MODEL-β | CNN (2 conv/pool + FC) | **SIM** architecture graph, weights and metrics |
| MODEL-γ | Transformer (2 MHA + FFN) | **SIM** architecture graph, weights and metrics |

The MLP series are real per-step loss, learning rate, gradient norm, accuracy and latency. CNN/Transformer series are deterministic simulated training curves with realistic decay, LR schedule, gradient norm and latency.

## Fields

- `models[].nodes` — layer/block/head nodes: id, label, type, params, activation, gradient.
- `models[].edges` — src, dst, type, weight, activation, gradient.
- `models[].series` — loss, lr, grad, acc, latency.
- `models[].weights` — per-layer norm, sparsity and 16-bin histogram.
- `models[].metrics` — final loss, LR, gradient norm, accuracy, latency, params.
- `models[].inference` — attention sample (transformer), latency and throughput.
