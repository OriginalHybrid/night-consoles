# DECLINATION data

This directory contains the deterministic model data and the offline fallback for
`themes/geomagnetic-field.html`.

## Files

- `igrf14coeffs.txt` — IGRF-14 coefficient table, IAGA / NOAA NCEI, 2024-11-18.
  Public scientific data. The theme uses the 2025.0 epoch and 2025–30 secular
  variation.
- `model.json` — generated by `specs/_tests/make-declination-data.mjs`.
  Contains the IGRF-14 coefficients used by the generator, the two magnetic dip
  poles, 18 port declinations, and historical pole positions.
- `field-lines.json` — generated by the same script. 260 field lines traced with
  RK4 from IGRF-14 footpoints. This is the baked geometry used by the hero
  canvas; live SWPC data drives its visual response.
- `fallback.json` — one last-good live snapshot baked by
  `specs/_tests/bake-declination-fallback.mjs`. It is a snapshot, not a live
  observation at read time.

## Regenerate

```bash
node specs/_tests/make-declination-data.mjs
node specs/_tests/bake-declination-fallback.mjs
```

The model generator is offline and deterministic. The fallback baker is a manual
network bake step.

## Model / data honesty

- Field geometry and port declinations are IGRF-14 model outputs.
- The extended outer cage is a visual magnetosphere, not a full MHD simulation.
- SWPC supplies live solar-wind, Kp, Dst, scale, alert and OVATION data.
- USGS Geomagnetism supplies the live BOU observatory magnetogram and declination.
- The map never labels model output as a live observation.
