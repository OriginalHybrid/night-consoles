# HARROW — Bennu source model

## Bennu_1_1.glb

NASA Science — **Bennu 3D Model** (NASA Visualization Technology Applications and Development, VTAD).

- Source: https://science.nasa.gov/resource/bennu-3d-model/
- Original file: https://assets.science.nasa.gov/content/dam/science/psd/solar/2023/09/b/Bennu_1_1.glb
- License: public domain (NASA).
- Use: decimated into `shared/data/harrow/bennu-mesh.json` (1,419 vertices / 2,692 triangles) and rendered as the real Bennu in the HARROW scene.

The freighter, hull, plate wear, and suit telemetry are original clean-room reconstructions and are not derived from this model.
