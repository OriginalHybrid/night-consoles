# GYRE WATCH assets

## ian-2022-ir.png

NOAA/NASA GIBS VIIRS NOAA-20 brightness-temperature image, 2022-09-27,
centred on Hurricane Ian south of Cuba. Public-domain U.S. government source.
The runtime maps cold cloud tops to a radar-like dBZ palette (warm eye and
land stay dark); it is a stylised satellite view, not measured radar reflectivity.
